# Video demo TugasIn

[![Sampul video TugasIn](tugasin-demo.jpg)](tugasin-demo.mp4)

[Tonton atau unduh video MP4](tugasin-demo.mp4).

Durasi 22 detik, 1920 x 1080, 30 fps, dengan musik dan efek suara. Video menampilkan alur pengumuman, pemeriksaan detail tugas, dan checklist.

Tampilan dianimasikan berdasarkan kode sumber TugasIn dengan data contoh berlabel **Simulasi alur**. Video ini tidak merekam panggilan Gemini secara langsung.
